# 互联网大厂向上管理课程设计 (Upward Management Masterclass)

> 从被动执行到价值共创：12周高维职场进阶实战手册与在线学习系统。

基于互联网大厂 OKR/KPI 实战协同场景，解构“帮上级成功 = 帮自己成功”的商业本质，破解职场人“献媚、盲从、对抗”三大心智误区，提供开箱即用的大厂生存与晋升工具包。

---

## 🌟 核心理念与阶段规划

- **第 1 月：认知与读懂** —— *先看清楚，再动手*
  - 破除工具人与讨好误区，建立信任账户底层框架，精准识别人格特质与组织杠杆点。
- **第 2 月：沟通与边界** —— *会说话，守边界*
  - 掌握结构化金字塔表达与报忧艺术，用一页纸降低决策成本，有策略地争取资源与守住边界。
- **第 3 月：价值与晋升** —— *让价值被看见*
  - 建设性化解冲突，撬动三大价值杠杆与跨部门影响力，精进 STAR 高级叙事与全流程综合实战。

## ⏱️ 每周标准教学结构 (60分钟单课闭环)

1. **开场回顾 (5min)**：作业点评 + 真实大厂痛点场景导入
2. **知识讲解 (25min)**：底层逻辑、概念定义、方法论框架
3. **案例拆解 (15min)**：大厂真实脱敏案卷深度剖析（正面高阶打法 vs 翻车现场）
4. **工具练习 (10min)**：模板套用、高情商话术推演、角色扮演
5. **课后行动 (5min)**：课后 Action Items 落地说明 + 下周预告

---

## 🛠️ 互动实战工具箱

1. **10分钟向上管理成熟度自测**：10 道大厂真实博弈场景题目，在线出具成熟度段位（L1~L4）与个性化改善雷达。
2. **5 类上级画像与攻防锦囊**：控制型、放权型、抢功型、甩锅型、导师型的识别信号、深层隐秘心理、DOs & DONTs 与必杀金句。
3. **4 步报忧话术生成器**：坏消息 + 原因剖析 + 方案 A/B + 倾向性建议，一键生成高情商汇报草稿。
4. **向上 1 页纸 (Executive One-Pager) 标准范本**：背景痛点、方案选型对比、核心推荐与 ROI、风险兜底预案。
5. **5 大建设性拒绝话术字典**：条件置换、降配 MVP、延期入池、升级决策、红线拒绝。

## 💻 本地运行与预览

本项目采用纯静态架构开发（HTML5 + Tailwind CSS + Vanilla JS），无需任何后端或打包构建，直接启动任意 HTTP 服务器即可查看：

```bash
# 进入项目目录
cd upward-management-course

# 使用 Python 启动本地 Web 服务器
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000` 即可畅爽体验。
